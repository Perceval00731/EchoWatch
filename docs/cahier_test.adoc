== I. Introduction
=== 1. Objet 
[.text-justify]
Ce document a été produit dans le cadre du développement d'une IHM de montre connectée **EchoWatch**. Il permet de formaliser les résultats attendus pour chaque comportement documenté.

== II. Pré-Requis 
[.text-justify]
L'exécution des tests spécifiés au chapitre suivant requiert :

* Montre EchoWatch connectée à un ordinateur ou une batterie
* Une connexion internet pour garantir le bon fonctionnement des tests

=== 1. Éléments à tester 
[.text-justify]
Les fonctionnalités sont testées selon les **fonctions** :

- **Localisation** : application, changement de couleur (chaud-froid)
- **Audio** : centre de contrôle, lecture via MQTT, TTS
- **Lumière** : contrôle, synchronisation MQTT
- **Accueil** : heure, batterie, accès aux applications

=== 2. Environnement de test 
[.text-justify]
Configuration recommandée :

* Système d’exploitation Windows/MacOS/Linux.
